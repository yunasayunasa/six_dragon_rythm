# 台本の書き方

コードを書かずに会話と演出を並べられる形式です。1行に1つずつ書きます。

## 3種類の行

```
ウィルナス（驚き）「なんだって！？」     ← 話す（表情は省略可）
空に浮かぶ港町。／日が沈むころ……        ← 「」が無い行はナレーション。／で改行
@カメラ ワムデュス                        ← 演出の命令
# メモ                                    ← # で始まる行は無視
```

- 名前は登場人物の表示名（`ウィルナス`）でもID（`wilnas`）でもOK
- 表情は事件データの `expressions` に書いた名前（通常・驚き・指差し・困惑・笑い など）
- 話す人には自動でカメラが寄ります（主人公の近くにいれば2人を収める構図）

## 命令一覧（共通）

| 命令 | 例 | 内容 |
|---|---|---|
| カメラ | `@カメラ ワムデュス` / `@カメラ ウィルナス ワムデュス` / `@カメラ 引き` / `@カメラ 灯台柱` / `@カメラ 戻す` | 寄り・2人・引き・舞台の物・探索カメラへ戻す |
| | `@カメラ 固定` / `@カメラ 自動` | 話者への自動カメラを止める／戻す |
| 表情 | `@表情 ワムデュス 怒り` | 表情だけ変える |
| 跳ねる | `@跳ねる ワムデュス` | ぴょんと跳ねる |
| 攻撃 / 被弾 | `@攻撃 ウィルナス` / `@被弾 ワムデュス` | 強く出る（溜め→ヒット→フォロースルー）／論破されてのけぞる。会話の立ち絵も同じ絵になる |
| カメラ（周回） | `@カメラ 周回 灯台柱 7` | 対象を中心に7秒かけて1周する |
| カメラ（眺め） | `@カメラ 眺め 飛空艇の着く所 16 2 -4` | 舞台の物を、距離・高さ・横のずれ（・画角）を決めて遠くから眺める。話者への自動カメラは止まるので、戻すときは `@カメラ 自動` |
| 演出 | `@演出 空魚 寄ってくる` / `@演出 飛空艇 到着` | 舞台の物に合図を送る（物ごとに決まった動き。終わるまで待つ）。第一話では、空魚が雲の下から昇って灯晶のまわりを泳ぐ・飛空艇が雲の下から来て桟橋に横付けする |
| 向き | `@向き ウィルナス ルオー` / `@向き ウィルナス 左` | 相手の方・左右を向く（紙が裏返る） |
| 移動 | `@移動 ルオー 2.5 -1.0` | x（と z）へ歩く |
| 登場 / 退場 | `@登場 フェディエル` | 床から紙が起き上がる／倒れて消える |
| 効果音 | `@効果音 発見` | 決定・選択・取消・入手・叫び・失敗・紙・発見・足音・紙起こし・きらり（キラキラ→ジャキーン）・ダン・ひび・割れる・破れる |
| 音楽 | `@音楽 エンディング` / `@音楽 止める` | BGMを切り替える（名前は `sound.defineBgm` で登録したもの） |
| ブレイク | `@ブレイク ワムデュス` | 論破の決め。斜めのカメラで3回「ダン！」と寄り、画面にひびが入って割れ、破片が飛び散る。割れた向こうで役者の紙が縦に裂けて倒れ、床から起き上がって元に戻る（最終尋問の決め台詞のあとに） |
| 会話を閉じる | `@会話を閉じる` | 会話枠と立ち絵を下げる（次のセリフでまた出る）。見せ場を画面いっぱいに見せたいときに |
| 揺れ | `@揺れ 0.4` | 画面を揺らす |
| 叫び | `@叫び そこだ！` | 大きな筆文字のカットイン |
| 待つ | `@待つ 0.5` | 秒数だけ待つ |
| 見た目 | `@見た目 confront 1` | Lookを切り替え（sunset / confront / dusk） |
| きらめき | `@きらめき ウィルナス` | 光の粒がはじける |
| 暗転 | `@暗転` / `@暗転 明け` | 画面を暗くする／戻す |
| 字幕 | `@字幕 題名｜小見出し｜ひとこと` | 章題カード（タップで閉じる） |
| たたむ / 組み立て | `@たたむ` → `@組み立て` | 舞台の紙・装置を床に倒す／左から順にパタパタ起こす（開幕用） |

会話中は、話し手の立ち絵が会話枠の後ろに出ます（主人公は左、相手は右。聞き手は暗くなる）。

## 逆転検事風ジャンルの命令

| 命令 | 例 | 内容 |
|---|---|---|
| 証拠 | `@証拠 ribbon` | 証拠品・推理メモを渡す（入手演出つき） |
| 記録 | `@記録 met_fediel` | 進行フラグを立てる |
| 灯り | `@灯り 灯台柱 つける` | 舞台の灯りをつける／消す |
| 対決 | `@対決 fediel` | 尋問を始める（`confrontations` の id）。正しい証拠をつきつけると成功の台本が流れ、そこで終わる |
| つきつけ | `@つきつけ kagachi_met` | 相手の問いに証拠品で答える（`challenges` の id。第三話から）。問い（`question`）は直前の台詞と同じ文にしておく（選ばずに閉じたら同じ声で問い直す）。尋問の成功の台本の中からも始められる |
| 事件解決 | `@事件解決` | 結末（`ending`）を流して「事件解決」 |

- 尋問の証言には `hidden: true`（最初は隠れている）と `reveals: 3`（揺さぶると3番の証言が出てくる）を書ける
- **証拠品（`evidence`）は尋問でつきつける物、推理メモ（`clues`）はまとめるで使う物**。尋問では証拠品だけ、まとめるでは推理メモだけが選べる
- 出てくる物はどれも必ずどこかで使う（使わない物を出さない）。`npm run test` が確かめる
- 「まとめる」は探索中いつでも開ける。`logic.pairs` の組が成立すると、その台本（ふつうは `@証拠` で次の推理メモを渡す）が流れる
- 調べる場所の `variants` は「条件を満たしたら差し替える台本」。`again` を書くと、それを一度見たあとはそちらが流れる。
  今の段階でまだ見ていない台本がある場所は印が跳ね、見終わった場所は小さな赤い ✓ になる
- 尋問の「信」（間違えられる回数）は事件全体で共通。尽きると「ゲームオーバー」→ その尋問を始めたときの信に戻して、最初からやり直し（満タンには戻らない）
- BGM は `bgm: { field: 'カフェ', confront: '尋問' }` で、探索中と尋問中の曲を決める。尋問ごとに `bgm: '追及'` と書くと、その尋問だけ曲を変えられる（犯人を追い詰める最後の尋問など。`追及` はコードで鳴らす緊迫した曲 `tenseBgm`）
- 尋問の始まりは、主人公と証人が斜めに割った画面で向かい合う対峙のカットイン（`Hud.versus`）。証拠品をつきつけると、その札が相手へ飛んで、正しければ刺さり、間違いなら弾かれる

書き間違い（知らない命令・いない人物・無い表情・無い証拠・無い尋問）と、最初から最後まで遊べるか（どこかで詰まらないか）は `npm run test` で見つかります。
