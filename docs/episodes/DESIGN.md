## 第二話「雲市場と二つの灯晶」

**あらすじ**: 星祭りの支度でにぎわう雲市場。市場の目印「市場灯」（灯晶）が台座から消え、なぜか**二つ**見つかる。
手代のトマは「台の下で拾ったこっちが本物。パレタの画材箱のは偽物で、こいつが盗んだ」と言い張る。
一方フェディエルとサンチラは、市場で拾った差出人不明の「恋文」に夢中で、書き主を探さないと手伝わないと言い出す（第一話のだんごと同じ型）。

**場所**
1. 市場の広場 … 市場灯の台座・空魚の水槽（シェロカルテの店の名物）・わたあめ屋台
2. シェロカルテ商会の帳場 … 台座の鍵・荷車の貸し出し帳
3. 昇降籠の乗り場（下の段） … トマの荷車。結末でトマが倒れているのが見つかる場所

**人物**: シェロカルテ（市場の元締め・トマの雇い主）、トマ（手代＝モブおじ。口が達者で調子がいい）、パレタ（市場を描いていた少年。疑われる）、
サンチラ（恋バナ好き。フェディエルと意気投合）、ルリア（食べ歩き中の目撃者）

**証拠品**
- 本物の灯晶（パレタの画材箱から。商会の前掛けの布に包まれていた）
- 偽物の灯晶（トマが「台の下で拾った」と持ってきた）
- パレタの絵（「鐘ひとつ」の市場を描いた絵。そのとき市場灯はまだ灯っている）
- 恋文（実は取引の符丁「次の荷は鐘ふたつ　昇降籠の下にて」）
- 封蝋のかけら（恋文の封。紋の一部が欠けている → **第五話で院長の印と照らし合わせる**）
- 荷車の貸し出し帳（トマが「鐘ふたつ」に荷車を借りている）

**推理メモ**: 二つの灯晶／空魚の言い伝え（第一話のおさらい）／水槽の空魚の様子（パレタの灯晶にだけ寄る）／台座の鍵（持つのはシェロカルテとトマだけ）
→ 偽物はトマの方／すり替えたのは鍵を持つ者／手紙はトマ宛ての取引

**まとめる**
1. 二つの灯晶＋水槽の空魚の様子 → トマの灯晶が偽物
2. トマの灯晶が偽物＋台座の鍵 → すり替えたのは鍵を持つ者
3. 恋文（符丁と分かったあと）＋荷車の貸し出し帳 → 手紙はトマ宛ての取引
4. すり替えたのは鍵を持つ者＋手紙はトマ宛て → トマが市場灯をすり替えて売ろうとした

**流れ**
1. 導入（広場）: 市場灯が消える → 灯晶が二つ見つかる → トマがパレタを責める。フェディエルとサンチラは恋文に夢中。
2. 尋問① トマ「パレタが盗むのを見た」→ **パレタの絵**（その時刻、パレタは離れた場所で描いていて、市場灯はまだ灯っている）。
   トマは「見間違いだった。だが本物は俺のだ」と言い直す。
3. 水槽に二つの灯晶を近づける → 空魚はパレタの方にだけ寄る（第一話の伏線の回収）→ まとめる①・②。
4. 尋問② サンチラ「恋文は逢い引きの約束」（トマとシェロカルテの恋だと思い込んでいる）→ **荷車の貸し出し帳**（逢い引きに荷車は要らない）
   → フェディエル「此方としたことが……！　これは恋文ではない。『次の荷は鐘ふたつ』……符丁ぞえ」→ 封蝋のかけらを入手 → まとめる③・④。
5. 尋問③ トマ「偽物はパレタが作った」→ **偽物の灯晶**（中の芯は灯晶院の職人の型。絵の具では作れない）
   → 続き「パレタの箱の灯晶には触っていない」→ **本物の灯晶**（包んでいたのはトマの名入りの前掛け）。
6. 尋問④ トマ「買い手なんて知らない」（追及曲）→ **封蝋のかけら**（灯晶院の紋）→ ブレイク。
   トマは青ざめて「買い手の名は、明日ぜんぶ話す」と約束する。
7. 引き: 翌朝、昇降籠の乗り場でトマが倒れているのが見つかる（黒く塗られた紙、手前で破れる）。
   ガレヲンが「甘くない、苦い花の香り」に気づく（**第三話で犯人を見分ける手がかり**）。
   ルオー（構え）「事故にしては、あまりに都合が良すぎるのだよ」

## 第三話「霧の工房と鐘の鳴らない夜」

**あらすじ**: 霧の町で、灯晶院の老職人ゲン爺が鍵のかかった工房で死んでいるのが見つかる。
町の人は「夜の鐘が鳴って、すぐ工房で物音がして、女が出てきた」と言う。前の晩に「恋の守り灯」を頼みに来ていたフェディエルが疑われる
（頼んだのはサンチラの恋のため。第二話とつながる）。

**場所**
1. 霧の町の通り … 夜警の証言・鐘楼が見える
2. ゲン爺の工房 … 遺体のあった作業台・小さな試し鐘・院の錠・墨の伝言（最初は見えない）
3. 鐘楼 … 霧で凍って固まった綱
4. 灯晶院の検品所 … 検品官カガチの持ち場

**人物**: ゲン爺（老職人＝モブおじ。故人、回想なし）、カガチ（灯晶院の検品官。役名。立ち絵と性格はハーゼリーラ＝表向きは礼儀正しく有能、裏は腹黒で手段を選ばない）、
ニオ（町の楽師。人の心が音で聞こえる。「あの夜の鐘は高くて小さかった」）、
カリオストロとクラリス（ゲン爺の古い友人の錬金術師。光で読める墨の仕組みを説明する）、マキラ（鐘楼の仕掛けの修理係）、夜警（帝国兵）

**証拠品**
- 夜警の日誌（霧で十歩先も見えなかった、と自分で書いている）
- 恋の守り灯（ゲン爺がフェディエルに渡した試作品。小さな**本物の灯晶**の灯り）
- 工房の錠（灯晶院の錠。全部の工房を開けられる合い鍵は検品官だけが持つ）
- 墨の伝言（本物の灯晶の光を当てると浮かぶ「カガチ／星祭り」。**残り半分は読めない → 第五話**）
- ゲン爺の古い帳面（二十年前の記録。「大罪人オロロジャイア」の名が初めて出る）

**推理メモ**: 凍った鐘楼の綱／ニオの聞いた音（高くて小さい）／工房の試し鐘（最近鳴らされた跡）／フェディエルが出た時刻（鐘より前）／甘くない香り（ガレヲン。第二話と同じ香り）
→ 聞こえたのは鐘楼の鐘ではない／鳴ったのは工房の試し鐘＝中にいた者が鳴らした／鐘のあと出てきた女はフェディエルではない／犯人は「甘くない香り」の主

**まとめる**
1. 凍った鐘楼の綱＋ニオの聞いた音 → 聞こえたのは鐘楼の鐘ではない
2. 鐘楼の鐘ではない＋工房の試し鐘 → 鐘を鳴らしたのは工房の中にいた者（時刻をずらした）
3. フェディエルが出た時刻＋甘くない香り → 鐘のあと出てきた女はフェディエルではない
4. 工房の中にいた者＋鐘のあとの女 → 犯人は「甘くない香り」の主

**流れ**
1. 導入: 霧の朝。工房でゲン爺が見つかる（黒い紙）。夜警がフェディエルを指さす。
   フェディエル（通常）「此方は頼みに行っただけぞよ。……其方らまで疑うのかえ」
2. 尋問① 夜警「赤い服の女が出てきた」→ **夜警の日誌**（霧で姿は見えていない）。
3. 鐘楼でマキラに会う → 綱が凍っている。ニオの証言 → まとめる①・②。
4. 尋問② フェディエル「頼み事をして帰っただけ」（味方の尋問。何かを隠している）
   → 揺さぶると隠れた証言「……ゲン爺から何も受け取っておらぬ」→ **恋の守り灯**（照れて隠していた）→ まとめる③。
5. ゲン爺の古い帳面を見つける → 「大罪人オロロジャイア」。
   ガレヲン（よそ見）「否定（……ロジャーは、そのようなことをする方ではありません）」（第一話「昔と変わりませんね」の意味が分かる）
6. 検品所でカガチに会う → ガレヲンが香りに気づく → まとめる④。
7. 尋問③ カガチ「夜の鐘のころは検品所にいた」→ **工房の錠**（鍵を開けて入り、閉めて出られたのは合い鍵を持つ検品官だけ）。
8. カリオストロとクラリスに頼み、守り灯の光を工房の壁に当てる → 墨の伝言が浮かぶ（残り半分は読めない）。
9. 尋問④ カガチ「職人とは会っていない」（追及曲）→ **墨の伝言** → ブレイク。トマを落としたことも認める。
   カガチ「院のためよ。……二十年前の夜を、また見たくなければ黙っていなさい」（台詞はカガチの口調に合わせる）
10. 引き: カガチは監獄船へ送られる。ルオーが一人、面会を申し込む。

## 第四話「嵐の監獄船とルオーの罪」

**あらすじ**: 嵐の中の監獄船で、カガチが独房で死んでいるのが見つかる。最後の面会者はルオー。ルオーは何も話さず、罪をかぶろうとする。
黙っている理由は、面会で「第一話の灯晶の外し方は、院が子どもに教えて試させたもの」と聞いたから。話せばワムデュスが院の手先と疑われる。

**場所**
1. 甲板（嵐） … 外からは誰も近づけない
2. 独房の通路 … 現場。換気窓に結ばれた綱
3. 面会室 … ルオーの面会の記録
4. 船倉 … 積荷の帳面・院の荷箱・燃え残りの命令書

**人物**: イルザ（看守長。口が悪い鬼教官）、ユーステス（看守。寡黙）、ゼタとベアトリクス（看守。にぎやか担当）、
ベリアル（院の使い。青い襟巻き。検品の書類を届けに乗っていた＝**第一話の旅の人**）、
ミオ（検品見習い。カガチの部下で、裏の顔を知らずに慕っていた。面会に来ていたもう一人の容疑者。役名、立ち絵はクラーバラ）、囚人・船員（帝国兵）

**証拠品**
- 独房の鍵の記録（面会のあとも、鍵は看守室から出ていない）
- 積荷の帳面（面会のあとに「院の荷」が積まれ、届けた使いが乗っている）
- 青い糸くず（換気窓の綱に絡んでいた襟巻きの糸）
- 古い結び目（換気窓の綱の結び方。**第一話の「古い釣り方」の結び**。ワムデュスと旅の人しか知らない）
- 燃え残りの命令書（船倉の炉から。院長の印の一部が残る → **第五話で使う**）

**推理メモ**: 嵐の甲板／面会の記録（ルオーが書き残した一行「子どもに試させた」）／ミオの面会時刻／第一話の旅の人（ワムの思い出：青い襟巻き）
→ 犯人は船の中にいた／面会のあとに乗った者がいる／院の使い＝旅の人／ルオーはワムをかばっている

**まとめる**
1. 嵐の甲板＋独房の鍵の記録 → 犯人は船の中にいた
2. 犯人は船の中にいた＋ミオの面会時刻 → 面会のあとに乗った者がいる（ミオは先に船を降りている）
3. 青い糸くず＋第一話の旅の人 → 院の使い＝旅の人
4. 面会の記録＋院の使い＝旅の人 → ルオーはワムをかばっている

**流れ**
1. 導入: 嵐の監獄船。独房のカガチ（黒い紙）。イルザ「最後に会ったのはそこの堅物だ」。
   ルオー（構え）「私が殺したと書いておきたまえ。それで終わる話なのだよ」
2. 尋問① イルザ「面会のあと独房に入れた者はいない」→ **独房の鍵の記録**の読み違いを正す（窓の外からなら……）→ 嵐の甲板を調べる → まとめる①。
3. 尋問② ミオ「カガチ様はそんな人ではない」（慕っていた人を失った悲しみ。犯人ではない）→ **積荷の帳面**（自分が降りたあとの積荷を知らない）→ まとめる②。
4. 尋問③ ルオー「私が殺した」（味方の尋問）→ 揺さぶると隠れた証言「面会で聞いたことは言えない」
   → ウィルナス（指差し）「終わらせぬ！　甘い推理で人を疑うなと言ったのは、お主であろう！」→ まとめる③・④。
5. 船倉で燃え残りの命令書を見つける。
6. 尋問④ ベリアル「私はただの院の使い」→ **青い糸くず**。
7. 尋問⑤ ベリアル「襟巻きの糸など、どこにでもある」（追及曲）→ **古い結び目**
   → ワムデュス（通常）「この人。ワムに、灯晶の外し方を教えた人」
   → ワムデュス（怒り）「ワム、怒られるのいやだった。でもルオーが怒られるほうが、もっといや」→ ブレイク。
8. 引き: ベリアルは院長の名を出さない（「星祭りの夜、すべてを照らすお方さ」）。雲上議会の命令でウィルナスは捜査権を取り上げられる。星祭りまであと一日。

## 第五話「暁の空に、六竜の逆転」

**あらすじ**: 星祭りの夜、空じゅうの灯晶が消える。雲上議会で院長ベルゼバブが「二十年前と同じ災厄だ、灯晶院に全権を」と求める。
議長バイシュラは**夜明けまで**だけ反論の場を認める。権限のない五竜は持ち場に散って証拠を集め直し、議場で院長と総決算の対決をする。

**場所**
1. 雲上議会の議場 … 対決の舞台
2. 凪ノ桟橋（第一話の舞台、夜） … 手動式の灯台だけが灯っている。ロジャーの灯晶
3. 雲市場（夜） … 封蝋の照らし合わせ（フェディエル・シェロカルテ・サンチラ）
4. 霧の工房（夜） … 伝言の残り半分を読む（ガレヲン・カリオストロ・クラリス）

**人物**: ベルゼバブ（院長）、バイシュラ（議長。たまにふざける）、サンダルフォン（議員。真面目、コーヒー好き。公平な立場）、
シエテ（議員として少し）、第二〜四話の脇役が持ち場で再登場

**持ち場の分担（主人公が交代する）**
- ウィルナス … 議場で時間を稼ぐ（院長と言い合う短い場面）
- フェディエル … 雲市場で封蝋のかけらと院長の印を照らし合わせる
- ガレヲン … 霧の工房で伝言の残り半分を読む →「最初の灯りは、古い灯りの下に眠る」
- ワムデュスとルオー … 凪ノ桟橋で、灯台柱の台座の下から**最初の灯晶**を掘り出す（ゲン爺が隠した。ロジャーの灯晶の下）

**証拠品**（前の話の物を持ち越す）
- 封蝋のかけら（第二話）と院長の印 … 欠けた所が一致
- 墨の伝言（第三話）・燃え残りの命令書（第四話）
- 最初の灯晶 … 本物の光でだけ読める、殺された職人の最期の記録
- 凪ノ桟橋の灯台（手動式で、すり替えられていない）

**推理メモ**: 消えた灯晶はみな院が配った物／凪ノ桟橋の灯台だけ灯っている／伝言の残り半分／院長の印 など（台本で詰める）

**流れ**
1. 導入: 星祭りの夜。空じゅうの灯りが消える。議場で院長が全権を求める。
   ウィルナスが割って入るが捜査権がない。バイシュラ「では夜明けまで。それまでに持ってこい」。
2. 持ち場の捜査（3か所。好きな順に回れる）。各持ち場で短いまとめる・小さな尋問（院の番兵＝帝国兵など）。
3. 議場の総決算の尋問（4段。最後は追及曲）:
   1. 「偽灯晶など知らぬ」→ 封蝋のかけらと院長の印
   2. 「職人殺しは部下の独断」→ 墨の伝言＋燃え残りの命令書
   3. 「二十年前の犯人はオロロジャイアだ」→ 最初の灯晶
      ウィルナス（指差し）「記録が何と書こうが知らぬ！　ロジャーは、仲間の灯りを奪う奴ではない！」
   4. 最後の一押し → 凪ノ桟橋の灯台
      ウィルナス（指差し）「刮目せよ！　お主が消せなかった灯りが、ここに一つだけ残っておる！」
   → 院長の開き直り →
   ウィルナス（指差し）「灯りは、帰ってくる者のためにある。誰を帰すか、お主が選ぶためのものではない！」→ ブレイク。

## 相手の問いに証拠品で答える「つきつけ」（2026-10-04 ユーザー決定。第三話から）

逆転検事のように、証言の矛盾だけでなく、相手の問い（「証拠があるなら見せてみろ」など）に証拠品で答える場面を入れる。第二話はこのまま。

- 遊び方: 相手の問いが出る → 証拠品の一覧から1つ選んでつきつける。外すと信が減り、ヒントが出て選び直し。尽きたらゲームオーバー（尋問と同じ）。
- 使う所（案。台本を書くときに決める）:
  - 第三話: サンダルフォンの推理対決（フェディエル犯人説）の締めで「違うと言うなら、鐘のあと工房に別の者がいた証拠を出せ」。カガチの最後の尋問の前に「私が職人と会っていた証拠でもあるのかしら」→ **墨の伝言**。
  - 第四話: ベリアル「旅の人が私だという証拠は？」→ **古い結び目**。
  - 第五話: 院長「その印が私の物だという証拠は？」→ **封蝋のかけら**（紋の欠け）。総決算の尋問の段の合間に入れる。
- 実装（第三話の実装のとき）: 台本の命令 `@つきつけ id`、事件データに問いの一覧（問い・答えの証拠品・成功・外れ・ヒント）。
  データ検査は尋問と同じ決まり（答えの証拠品を持つまで始めない・証拠品は尋問かつきつけのどこかで使う）。
